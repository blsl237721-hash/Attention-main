controlnet  folder
This directory contains the official implementation source code of the ControlNet series models in the Hugging Face Diffusers library and is part of the model layer.
The directory also includes ControlNet implementations for different base diffusion models:
controlnet_sd3.py → ControlNet adapted for Stable Diffusion 3
controlnet_flux.py → ControlNet adapted for FLUX.1
controlnet_sana.py → ControlNet adapted for the SANA architecture
controlnet_hunyuan.py → ControlNet adapted for Tencent's HunYuan architecture
controlnet_qwenimage.py → ControlNet adapted for the Qwen-Image architecture
